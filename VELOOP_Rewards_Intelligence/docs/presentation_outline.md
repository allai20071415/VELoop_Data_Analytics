# 7–8 minute internship presentation

1. **Problem and objective (45 sec):** VELOOP has multiple measurable product areas; the objective is to propose a reliable analytics foundation and prove it with a working dashboard.
2. **Data integrity (45 sec):** all supplied working records in this demonstration are synthetic; the project never represents them as company results.
3. **Analytics design (90 sec):** explain the 38 proposed events, 104-field dictionary, logical model and 46 KPI definitions.
4. **Working dashboard (2 min):** demonstrate overview, user, task/reward, wallet/withdrawal, referral and data-quality views.
5. **Quality controls (60 sec):** show deliberate duplicate, missing-ID and invalid-status test cases and explain quarantine/review.
6. **Company value (60 sec):** explain how approved production sources could enable reconciliation, queue monitoring and consistent reporting.
7. **Limitations and next steps (60 sec):** request engineering confirmation, pseudonymized test export, KPI sign-off, security review and pilot sponsorship.

## Closing statement
This is an executable proof of concept and a proposed implementation foundation. It is not connected to VELOOP production systems. With approved data access and stakeholder validation, it can be piloted as an internal analytics tool.
