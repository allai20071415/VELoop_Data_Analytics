# Submission checklist

## Before GitHub upload
- [ ] Extract the ZIP and open the project folder in VS Code.
- [ ] Install requirements and run the app locally.
- [ ] Test the demo login and each dashboard tab.
- [ ] Run `pytest -q` after installing dependencies.
- [ ] Keep `.env`, credentials, production exports and database files out of Git.
- [ ] Confirm every screenshot/report labels data as synthetic.

## Before sending to VELOOP
- [ ] Include the public GitHub repository URL.
- [ ] Include the live demo URL only after deployment succeeds.
- [ ] Attach the executive summary and project presentation.
- [ ] State clearly that production integration is pending authorization.
- [ ] Ask for a technical review and a pseudonymized sandbox/export if they want to evaluate production applicability.

## Company handover prerequisites
- [ ] Engineering confirms identifiers, event names, source ownership and status histories.
- [ ] Product/Finance approves KPI definitions and reward unit/currency semantics.
- [ ] Security/Privacy approves access, retention, audit, hosting and data processing.
- [ ] A named owner accepts monitoring, support and maintenance responsibilities.
